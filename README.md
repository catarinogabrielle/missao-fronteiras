# 🌍 Missão Fronteiras: O Chamado (3D MOBA + Mundo Aberto PWA)

Jogo web 3D educacional e gamificado em **Next.js (App Router) + Three.js + TypeScript + Tailwind CSS + Framer Motion**, criado para ensinar **Missões, Evangelismo Transcultural e a Mensagem do Evangelho** a **Juniores (9–12 anos)** e **Adolescentes (13–17 anos)**.

## ✨ Funcionalidades Principais

- **Mundo Aberto 3D Estilo MOBA + GTA (`160x160` em Three.js):**
  - **4 Cidades & Regiões 3D Vivas:** Avenidas, calçadas, 16 quarteirões/construções 3D texturizadas, tráfego urbano, Rio com 3 Pontes e Barco-Hospital na Amazônia, arranha-céus neon em Tóquio, arquitetura da Janela 10/40 e vilas de Moçambique.
  - **Veículos Táticos 3D Dirigíveis (`[V]`):** *Quadriciclo Anfíbio Ide*, *Jipe Tático Deserto*, *Cyber-Moto Neon Ide* e *Jipe Safari 4x4*.
  - **Combate MOBA em Tempo Real + Bosses:** Ataque básico em combo (`Espaço`), `Q` Pulso de Luz, `W` Dash Tático, `E` Escudo de Oração + Cura e `R` Ultimate *Luz das Nações* contra Sombras patrulheiras e Bosses de Distrito.
  - **Missões com Moradores (`👥 Pessoas`) & 25 Colecionáveis 3D por Mapa:** Resgate, entrega de suprimentos, encorajamento, Pergaminhos da Palavra, Cristais de Sabedoria e Radar Minimapa com Seta GPS 3D.
- **PWA Instalável & 100% Offline:** Manifesto Web App, ícones 3D dedicados e Service Worker (`sw.js`) com cache completo de assets, texturas procedurais via Canvas e áudio Web Audio API sem dependências externas.
- **Criação de Campeão da Base Ide:** 4 heróis com artes 3D e modelos articulados (*Lucas*, *Sofia*, *Davi*, *Ester*) e 4 Dons/Habilidades iniciais com bônus reais no gameplay.
- **Globo Holográfico 3D & 4 Missões Completas:**
  1. 🛶 **Amazônia Ribeirinha (Brasil)** — Cauã (12 anos) • *1 João 3:18*
  2. 🕌 **Janela 10/40 (Norte da África)** — Tariq (15 anos) • *Efésios 2:8*
  3. 🌸 **Metrópole Digital (Tóquio, Japão)** — Hina (14 anos) • *Mateus 11:28*
  4. 🌍 **Savana & Vilas (Nampula, Moçambique)** — Samora (11 anos) • *Romanos 10:14*
- **Pontes de Empatia, Decodificador da Palavra & Cards Lendários 100%:** Diálogos com cobertura de oração, tradução bíblica cronometrada, Passaporte Missionário, Bíblia de Bolso (*O Evangelho em 4 Passos*), Radar de Intercessão, **Desafio de Tribos** (Quiz Multiplayer Local) e **Painel do Líder** (PIN `1234` + Modo Telão).

## 🚀 Como Rodar Localmente

```bash
npm install
npm run dev
```

Para testar o modo **PWA Offline de Produção**:

```bash
npm run build
npm run start
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.
